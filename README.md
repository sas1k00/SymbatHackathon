# Founder Cup Anywhere

Прототип для хакатона AI Startify Global Growth Challenge, направление 2 (Startup Creation & Activation).
Не официальный продукт AI Startify. Все кубки, команды и цифры в прототипе являются демо-данными.

**Идея.** Любой учитель, клуб или вуз за 10 минут запускает локальный кубок стартапов. Публикация проекта служит входным билетом. Победители идут в городской, национальный и международный финал.

## Что есть в MVP

- Запуск кубка: форма, код из 6 знаков, страница кубка, набор организатора
- Вход по коду и публикация проекта из 6 полей
- Предпроверка проекта с баллом и подсказками (в демо по правилам, в продукте VOI Engine)
- Голосование, рейтинг: 50% жюри + 30% предпроверка + 20% голоса (не больше 100 в зачёт)
- Панель жюри и объявление победителя
- Сертификат с кодом проверки и проверка кода на странице лиги
- Лига: страны, рейтинг организаторов, путёвки в следующий этап
- Калькулятор пути к 10 000 проектов с явными допущениями
- Русский и английский интерфейс, светлая и тёмная тема, телефон

## Запуск

Откройте `index.html` в браузере. Сервер не нужен, данные хранятся в браузере.

`app.html` содержит исходник страницы. `sh build.sh` собирает из него `index.html`.

## Ограничения

- Нет бэкенда и аккаунтов: один браузер, один пользователь
- Предпроверка в демо работает по простым правилам, а не через ИИ
- Интеграции с AI Startify нет
